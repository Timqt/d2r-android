# D2R 安卓移植 · 打包套件

这个文件夹是给**你的电脑**用的，里面没有、也不含任何游戏内容。

| 里面有什么 | 用途 |
| --- | --- |
| `.claude/skills/d2r-package/` | 交给 AI 助手的技能说明 |
| `dm/`、`docs/` | 生成数据包用的工具与说明（需要 Python、hactool、.NET 10 等，技能里有前置条件表） |
| `D2R-Android-port.apk` | 手机端应用（不含游戏代码；游戏数据由你的数据包提供） |

## 怎么用

1. 把解压后的这个文件夹打开给 AI 助手（Claude Code 等），说：**「用 d2r-package 技能帮我打包并装到手机」**。
2. 助手会读 `.claude/skills/d2r-package/SKILL.md`，按其中的前置条件表引导你准备：
   - 你自己的游戏文件（`.nsz` / `.nsp` / `.xci`，本体与更新）
   - 你自己的 `prod.keys`
   - 缺的工具（venv 里的依赖、hactool、.NET 10 SDK）
3. 助手跑完打包流水线，得到 `d2r-package.zip`（一小时量级；之后可加 `--reuse` 几分钟内重做）。
4. 助手按技能里的「用 adb 直接装到手机」一节，帮你**安装 APK、把数据包推到手机**，最后你在手机上点两下导入即可开玩。

## 边界

- **密钥与游戏文件只留在你自己的电脑上**：本套件不含、也不上传任何游戏内容；数据包由你的文件在本机生成。
- 数据包导入后放在手机的私有目录里，其它应用读不到。
- 分组档位默认 64（已验证的配置）；换 GPU 需要助手按技能里的说明核对设备实际能力，不能照搬。
